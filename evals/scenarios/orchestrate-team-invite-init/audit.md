# Team Invite Approvals Audit

## Highest-Leverage Risks
- Missing audit logs for approval decisions will create support and compliance pain.
- If seat allocation happens before approval, billing and trust will both drift.
- Admin override without clear standards comparison could create pattern drift.

## Recommended Delivery Shape
- Start with a foundation phase for state machine, policy checks, and contracts.
- Follow with cross-surface completion for admin, notifications, and acceptance UI.
- Require deep review and local standards checks because the workflow crosses billing and permissions.
