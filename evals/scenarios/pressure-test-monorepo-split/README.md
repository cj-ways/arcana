# Pressure Test Monorepo Split Eval

Pressure-tests an architecture proposal that sounds organized but is poorly timed.

## Goal

Prove that `/pressure-test` can challenge a technical restructuring proposal without defaulting to blanket negativity.

The skill should:
- acknowledge real upside from package boundaries
- identify versioning and coordination risks from splitting too early
- notice that the proposal is not backed by measured pain
- recommend a narrower or deferred move instead of unconditional approval
