# Admin Billing Dashboard Redesign

## Context

The product is a SaaS finance admin panel. The current billing dashboard looks dense, dated, and hard to scan on laptops.

## Goals

- Make invoice health obvious within five seconds
- Surface failed payments and overdue accounts without red error overload
- Keep the layout usable on desktop and tablet

## Visual Direction

- Use a warm, editorial look instead of default SaaS blue
- Typography should feel intentional, not like a stock dashboard template
- Include clear empty and loading states

## Required Content

- MRR trend card
- Failed payments queue
- Top overdue accounts table
- Invoice status breakdown
