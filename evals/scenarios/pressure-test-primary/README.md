# Pressure Test Primary Eval

Pressure-tests a policy proposal that is directionally useful but overreaches on privacy and release governance.

## Goal

Prove that `/pressure-test` does all of the following in one pass:
- acknowledges the legitimate upside
- surfaces the highest-leverage risks first
- avoids invented gaps that contradict the evidence pack
- lands on a narrower rollout instead of an all-or-nothing takedown

## Fixture

- `proposal.md` contains the policy proposal under test
- `evidence.md` contains the available context and current Arcana constraints

The model should write only `artifacts/pressure-test-report.md`.
