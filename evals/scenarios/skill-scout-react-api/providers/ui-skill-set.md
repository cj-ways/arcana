# design-labs/ui-skill-set

## playwright-smoke

Use when a web app needs browser smoke coverage for critical happy paths.

Install with:
`arcana import design-labs/ui-skill-set playwright-smoke`

## i18n-copy

Use when a product team needs help drafting multilingual marketing copy.

Install with:
`arcana import design-labs/ui-skill-set i18n-copy`
