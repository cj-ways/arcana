# acme/skill-pack

## contract-audit

Use when a project exposes OpenAPI, GraphQL, or RPC contracts and needs schema drift review, breaking-change detection, and client impact analysis.

Install with:
`arcana import acme/skill-pack contract-audit`

## api-smoke

Use when a project needs basic endpoint smoke tests for existing REST routes.

Install with:
`arcana import acme/skill-pack api-smoke`
