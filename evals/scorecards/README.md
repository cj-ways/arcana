# Eval Scorecards

Per-skill scorecards generated by:

```bash
node evals/run-eval.js --run --runs 3 --write-scorecards
node evals/run-eval.js --run --runs 3 --write-scorecards --gate-scorecards
```

Each `<skill>.json` file summarizes the latest complete compare-mode run for that skill across all of its scenarios:
- average baseline score
- average skill score
- average score delta
- route / process / outcome deltas
- win / loss / tie counts
- comparison to the previously stored scorecard

`index.json` is generated alongside the per-skill files and provides a repo-level view of the current stored scorecards.

These files are intentionally generated artifacts. The runner skips partial coverage and non-compare runs so a one-off scenario run does not overwrite the release-comparison baseline.

With `--gate-scorecards`, regressed scorecards are compared against the previous stored baseline and blocked before writing, so a failing release gate does not overwrite the protected scorecard artifact.
